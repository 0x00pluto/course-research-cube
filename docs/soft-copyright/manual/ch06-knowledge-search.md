## 第6章 知识检索

**功能说明：** 在功能模块库、案例素材库、培训师技巧库中按关键词或条件检索，为课程设计提供可复用内容与来源标注。

**操作步骤：**

1. 在左侧导航展开「知识库管理」，单击「知识检索」进入检索页。
2. 在顶部搜索框输入关键词（如「多维表格」「互动」等），或选择类别筛选（模块 / 案例 / 技巧）。
3. 单击「搜索」或按回车，系统在下方列表展示匹配条目及来源类型、更新时间。
4. 单击某条条目的标题或「查看详情」，阅读完整内容与适用场景，决定是否纳入当前课程框架。
5. 设计过程中可将合适条目记为参考；若检索无结果，可转至「新增知识」提交补充。
