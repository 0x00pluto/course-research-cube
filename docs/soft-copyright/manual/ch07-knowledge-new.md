## 第7章 新增知识

**功能说明：** 当知识库缺少所需模块、案例或技巧时，设计人员可提交新条目，经审核通过后进入正式库供全员复用。

**操作步骤：**

1. 在「知识库管理」下单击「新增知识」，打开录入表单。
2. 在「类别」下拉框中选择 MODULE（功能模块）、CASE（案例素材）或 TRAINER_TIP（培训师技巧）。
3. 填写「标题」与「内容」正文，内容应包含可讲授要点、使用场景或授课建议。
4. 确认来源类型（知识沉淀 / 手工录入等，以页面选项为准）后，单击「提交」或「保存」。
5. 提交成功后，条目进入待审核状态；培训负责人可在列表中审核通过或驳回。
