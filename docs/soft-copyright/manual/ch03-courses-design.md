## 第3章 发起课程设计

**功能说明：** 按「课型 → 目标学员 → 用户问题」建立设计上下文，补充四类输入后获取系统推荐的课程框架，经人工调整后生成大纲、练习册与课件包。OPC 讲师在开始设计时会按次扣除积分。

**操作步骤：**

1. 在左侧导航展开「课程设计中心」，单击「发起设计」进入设计向导页。
2. **第一步**：在列表中选择本次课程的课型（如半天公开课、一天技能课等），单击「下一步」。
3. **第二步**：选择目标学员类型，确认系统展示的授课注意提示后，继续「下一步」。
4. **第三步**：勾选或选择本次要解决的核心用户问题，进入输入维度页面。
5. 分别填写「市场竞品」「用户洞察」「产品植入」「授课技巧」四个文本区域，填写完成后提交或进入「推荐框架」步骤。
6. 单击「生成推荐框架」，待系统返回草案后，在框架编辑区增删模块、拖动或调整顺序与重点说明。
7. 确认结构无误后，单击「生成成果」或等价按钮，等待系统输出课程大纲、练习册与课件包；可在结果区查看来源标注与缺失风险提示。
8. OPC 用户若弹出扣费确认框，阅读规则后单击确认，扣费成功后方可继续设计。
