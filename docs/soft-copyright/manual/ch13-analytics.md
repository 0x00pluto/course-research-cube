## 第13章 质量看板

**功能说明：** 面向培训负责人与管理层，汇总多期课程的质量指标与趋势，辅助判断优化成效与停开/续开讨论（系统仅提供参考，不替代人工决策）。

**操作步骤：**

1. 使用 **培训负责人** 或 **平台管理员** 账号登录（账号需具备「质量看板」菜单权限）。
2. 在左侧导航单击「质量看板」进入数据看板页。
3. 如有时间范围选择器，设定统计起止日期后单击「查询」或等待自动刷新。
4. 查看页面中的关键指标卡片与趋势图（如平均分变化、模块薄弱分布等，以实际展示为准）。
5. 将看板结论用于内部复盘会议；需要下钻到单课细节时，可转至「质量分析」或「管理后台」。
