## 第19章 公开问卷页

**功能说明：** 学员通过培训师下发的问卷链接，在无需登录平台的情况下填写评分与文字反馈，数据写入对应课程的反馈库。

**操作步骤：**

1. 在手机或电脑浏览器中打开培训师提供的完整问卷链接（地址中包含 `/survey/` 与一串字符）。
2. 阅读页面顶部的课程名称与问卷说明，确认是本人参与的那门课。
3. 按页面提示对各模块或整体进行评分（通常为 1～5 分），在文本框填写具体意见。
4. 检查填写完整后，单击「提交」按钮；页面显示感谢或成功提示即表示回收成功。
5. 若链接失效或提示问卷不存在，请联系培训师重新获取有效链接。
