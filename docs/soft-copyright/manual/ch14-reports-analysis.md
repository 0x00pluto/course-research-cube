## 第14章 质量报告

**功能说明：** 在反馈达到最低条数且经审核后，按课程生成结构化质量分析报告并归档；OPC 讲师生成报告时按次扣除积分，重复查看不重复扣费。

**操作步骤：**

1. 在左侧展开「报告与分享」，单击「质量报告」。
2. 在「选择课程」下拉框中选中目标课程；确认页面提示的「至少 N 条已审核反馈」条件已满足。
3. 单击「生成分析报告」，等待系统处理（OPC 用户需确认积分扣费提示）。
4. 生成完成后，在「历史报告列表」中找到对应报告，展开「查看完整报告正文」阅读综合评分与建议。
5. 需要迭代课程时，可单击「编辑当前课程」或「基于此发起新版设计」跳转到课程模块。
