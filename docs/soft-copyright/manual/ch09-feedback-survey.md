## 第9章 课后问卷

**功能说明：** 为已交付课程创建结构化课后问卷，生成公开填报链接发给学员，回收的评分与意见进入反馈库供分析。

**操作步骤：**

1. 在左侧「反馈与质量分析」下，单击「课后问卷」。
2. 在「选择课程」下拉框中选中已结束或进行中的目标课程（须本人有权限且课程已存在）。
3. 单击「发起问卷并获取链接」，系统生成唯一 token 并在页面展示填报地址（形如 `/survey/xxxx`）。
4. 复制完整链接，通过微信群、邮件等方式发送给学员；页面「已发起的问卷」区域可查看回收份数。
5. 学员提交后，数据进入反馈库，可在「反馈列表」与「质量分析」中查看（需经审核的须先审核）。
