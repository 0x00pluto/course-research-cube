## 第17章 管理后台

**功能说明：** 平台管理员查看内部员工与 OPC 两侧课程资产概览、运营数据与关键配置入口，实现双侧全景掌握且不改变前台数据隔离策略。

**操作步骤：**

1. 使用 **平台管理员** 账号登录（如 admin 角色账号）。
2. 在左侧导航单击「管理后台」进入总览页。
3. 浏览页面中的课程数量、反馈统计、OPC 使用情况等汇总指标（以实际布局为准）。
4. 在课程列表或分区中区分「内部」「OPC」来源，单击某一课程进入详情页做全量查看。
5. 需要审计或策略调整时，结合平台设置与业务规范在后台完成查看与记录，不在此修改讲师侧课程归属。
