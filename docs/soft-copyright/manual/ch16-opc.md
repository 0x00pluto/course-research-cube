## 第16章 OPC 积分

**功能说明：** OPC 讲师查看积分余额、扣费流水与计费规则；开始课程设计、生成分析报告时按次扣费，余额不足时无法继续操作。

**操作步骤：**

1. 使用 **OPC 讲师** 账号登录后，在左侧导航单击「OPC 积分」。
2. 在页面顶部查看「当前余额」及最近一次扣费说明。
3. 向下滚动查看「扣费记录」表格，核对每次设计或报告生成的时间、类型与扣减积分。
4. 阅读页面中的计费规则说明（开始设计即扣费、中途放弃不退还、报告重复查看不重复扣费等）。
5. 若余额不足，按页面提示联系运营充值后，再返回「发起设计」或「质量报告」继续使用。
